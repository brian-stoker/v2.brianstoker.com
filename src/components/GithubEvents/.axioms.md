# AX-HOMEPAGE-WORK-PREVIEW: Homepage navigation is opt-in and excludes the repo strip

## Why
The homepage Work showcase is a preview of /work, not the full activity browser.
Visitors must be able to open /work from any point below its repository selector.

## How to apply
Only GithubEventsShowcase opts into workPreview and alwaysColumn. Its entire
read-only timeline is one native, keyboard-accessible /work anchor, with no
nested anchors or interactive descendants. Keep the repository strip outside
that link so it still filters in place. Default GithubEvents usage, including
/work, preserves event selection and external links. Do not replace this with
bubbling click handlers that compete with event actions.

## Acceptance Checks
- Run e2e/work-preview.spec.ts in a real browser at mobile and desktop widths.
- Card, event-label, date and background clicks below the strip navigate /work.
- Enter on the focused preview link navigates /work.
- Repo strip filters without navigation, and /work keeps normal interactions.
