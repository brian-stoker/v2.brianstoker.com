### selfactor

#### lander

- main moved again after the stall: twenty-four version bumps to 0.2.398, twenty task branches squash-landed from morning to evening
- re-validation no longer fails on a loopback fixture that inherited nonblocking, and the lander carries refreshed authority instead of inferring it

#### catalog

- the catalog project ran all night on scoped persistence: fenced parent writes for project and task references, artifact associations with version snapshots, immutable documents staged before their pointer commits
  - canonical artifact and work filter browsers, tenant-scoped association selectors, verified family membership readback
  - cyclic provider dependency resolution fixed at the end of the run

#### console

- organizations rename from Settings: a gated patch, a slug another org owns refused, `org.updated` written to the activity log, the new Organization tab reachable from the user menu

#### governance

- the judge timeout was analysed and the judging path reworked around it
- phase one readiness checkers for agent-ownable work landed with tests

#### build

- build GC deletion engine hardened: unlink through verified descriptors, explicit artifact allowlist, Cargo layout recognised
- mono private cutover got a report, a verifier and a nightly export workflow

### gdock

- gdock became Zerk: app name, menus, docs, CLI verb, setting ids and bundle id, plus a first-launch migration that copies settings, preferences, app data, browser storage and agent-chat journals
- blank panel space traced to a retiring terminal mount detaching a terminal a replacement host had already adopted; ownership guard with four-panel and viewport tests
- repo sidebar parity, org icon gone from repo nodes, menubar tray guard rewritten to build once and mutate in place
- splash self-test measures playback time instead of wall clock
- chat got its browser images back, with attachment controls and a browser composer

### selfagent

- composites nest: a nested composite from the context menu, and deleting one removes it from the structures that nest it
- installation picker precedence fixed, the response task continues after the pick

### sgit

- repo renames preflight before they start and a locked relocation is approved rather than failing, with a rename test suite
- menubar app back in the workspace, build pointed at the right frontend output
