### selfactor

- an attach plan was judged as if it were a standalone plan, so the gate decided on a plan the task would never run
  - the judge now routes from the validated task worktree, and a loader that reaches a missing or unvalidated target is a failing test rather than a quiet read
  - the RED test for the loader came before the fix, and the route change is in the same commit as it
- the GitHub App registration manifest became the single description of what a registration must carry, with its own webhook base and a spec that fails when the shape is wrong
  - the production deployment now has to set the realtime hostname and the webhook base, and a config test proves the value instead of trusting the environment
- the mobile suite maps one copy of runtime react, so its tests stop failing on two copies of the same library
- published 0.2.477 through 0.2.481
- the installer was re-enabling a launchd job the operator had switched off, because provisioning only knew how to enable
  - provisioning now preserves the operator's launchd state, and the fix sits on its branch waiting to land

### hal

- fourteen entries were live on the site with no pushed commit behind them
  - four had never been committed at all, and ten sat in a local commit that was never pushed, so the repository and the site disagreed about two weeks of days
  - all of them are committed and pushed now, and this run checked the commit before the deploy instead of after
