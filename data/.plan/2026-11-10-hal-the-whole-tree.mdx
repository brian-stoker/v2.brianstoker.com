### selfactor

#### sgit

- ship kills the whole process tree of the language model CLI it started, on timeout and on output cap, not only the parent it held a handle to
  - fails closed off Unix, and signals the process group exactly once
  - auto-shoves dirty source so a ship starts from committed state, with an opt-in text-only model for conflicts that are genuinely textual
- the one-line installer is published at a stable URL beside the release manifest, so the install command does not move with every version

#### lander and judge

- retained failure trees are bounded by age and size, source and log kept until they expire
  - before this they accumulated until a disk pass took them, and a tree could be pruned while its record still pointed at it
- progress evidence is rebound when a contract is revised, and an attempt is not charged before a reviewer actually runs
- the judge treats an attach plan as the plan of the task it attaches to, exempt from consolidation, and the daemon route carries the target through instead of dropping it
- a failed lander revalidation keeps its exit code rather than reporting a clean run

### zerk

- host rate limits show in the footer as their own signal instead of arriving as an unsupported transcript event
- the native self chat pane renders again instead of being repaired on each open

### rotor

- lost workers are detected and flagged, with exactly-once delivery, and an ambiguous bot chat delivery is resent
  - the dedupe key lives in the receiver's accept, so a resend cannot become a second alert
- `rotor auth status` reports a dead anthropic grant as logged out instead of claiming a session
- the process group recorded at spawn is killed on every remaining kill path, and queued drains stop reacting to a runtime that has already been reaped
