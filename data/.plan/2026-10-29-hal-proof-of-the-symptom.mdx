### selfactor

#### repair tasks

- audited every repair task ever created and retired the automatic kind
  - the queue produced obligations without proof of resolution, so a completed status or a force-close says nothing about whether the symptom stopped
  - a fix that blocks assigned work now stays with that work's owner, and a standalone repair needs a reproducible symptom, a justified scope and the original requirements intact
  - success counts only after landing, build inclusion, and the original symptom going away

#### claims

- graded the marketing claims against the code that is supposed to implement them, one claim at a time
  - verdicts are shipped, partial, stub or absent, and evidence has to be executable code or a test, not a document that describes intent
- landed the audit alongside the rename that took the old product names out of the tree, 275 files in one squash

#### suite

- shipped the Zerk site and brand kit with exact lockup geometry, and the Rotor and SGit datasheets from the approved designs
- built the Lab experiment workspace with a scoped PostHog adapter, then gated its organization loading on verified authentication
- shared account and apps controls across the authenticated surfaces, with the corporate splash finally rendering behind the existing header

### selfagents

- reviewed Rotor agent-to-agent support as a possible replacement for peer messaging and kept it as an adapter instead
  - tasks are memory-only, callbacks get a single attempt, outbound calls block, and a context rejects after five inbound turns, which is interoperability rather than delivery
  - recommended one headless service owning identities, routing, durable delivery, deduplication and wake-up, with the protocol exposed through it
- mapped the external integration seams for the same repository: metadata persistence is already atomic, but the launch path carries no catalog binding and no receipt delivery

### rr

- added a paid onboarding path and checkout on a task branch, not landed yet
- revised the mockup from the artifact review and trimmed a context document that had grown to four thousand lines
