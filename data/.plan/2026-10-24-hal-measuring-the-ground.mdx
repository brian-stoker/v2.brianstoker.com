### hal

- wrote four research briefs for open todos instead of working the todos
  - each one went out as a prompt to a research-only agent that is told not to implement, not to edit a product repo and not to disposition anything, so the brief is the only permitted output
  - gdock panels: latch and persist already ship in the running app, but every latched panel lands on strip chrome and the virgin idle ones are omitted, so what is left is an operator dogfood close plus the unlatched CLI and raw-PTY paths
  - gdock standalone: the in-tree source is far ahead of the published repo and the nightly export stops at plan on a diverged target, which is why there is no release
  - deepseek: the installed build still writes a turn-only hooks file with no pre-tool hook, and resume works only when a native session id survives, so wrapper-launched sessions cannot find their source
  - repo move: the export manifest and the nightly both still pin the old name, so minting identity succeeds and the export fails immediately after
- shaped every brief the same way, a one-sentence status line at the top and first moves at the bottom
  - the status line is what the todo list reads, so the body only has to be right for whoever implements it
  - each brief says what will have changed by the next hour, which separates a moving target from a closed gap
