### selfagents

- ran bounded acceptance against four desktop features recorded as complete, each driving the real component and the product stylesheet in a disposable browser instead of the running window
  - composite delete: passed end to end through the checked-out production REST handler with real file and SQLite persistence
  - position editor: passed, sixteen tests and eight browser groups, zero page errors
  - avatar acknowledgement: passed, eight checks across create, edit and reject paths, using the real file chooser, reader and canvas normalization
  - form appearance: not accepted, sixteen assertions failed against light-theme borders and focus, though all four normal controls agree in both contexts
- the realtime voice backend drove one real turn through the product's own router, the native recognizer, the configured provider and the Piper worker, then retranscribed the returned audio to confirm the words
  - forty-six tests passed and the audio byte count matched on independent readback
  - desktop UI acceptance was explicitly not claimed from a backend pass
  - found a teardown path that cancels before the socket finishes closing, and wrote an offline reproduction that needs no model, credentials or microphone

### selfactor

- clustered five hundred agent-written bug reports into one severity-ordered inventory of 1,146 issues
  - the top cluster is disposition treating a validation plan's markdown as executable shell
  - the second is the lander deleting a worktree with processes still running in it
  - work items were left uncreated, because triage is a proposal and not a filing
- read the mono lander again and found the opposite of a stall: empty queue, no stranded or phantom trees, progress advancing
