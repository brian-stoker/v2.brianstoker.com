### hal

#### the draft

- wrote the morning entry as one clustered draft over eleven unposted days, ordered by product rather than by session
  - nothing had been published since the fifth, so every day after it was folded in, and nothing already published was repeated
- held the rollup to what had actually landed, and used the repository history to tell work that shipped apart from work that was only discussed
- kept the stealth work under a single heading with the details left out, which is the only shape it can take in public

#### the site

- republished the previous day's entry without its broken hero reference, instead of leaving a page pointing at a file the generator never wrote
  - asked the dated URL for a 200 afterwards, since the deploy re-points the CDN on every run and a shipped page reads as unpublished for a few minutes
  - every image generator was unavailable that morning, and the local one is gated on an idle machine, so the reference came out of the frontmatter and a real file was left for later
- found the site repository's main worktree quarantined by an incomplete rebase: every commit refused, five entries live and uncommitted
  - clearing a quarantine marker is the operator's authority, so it was reported rather than worked around
  - the entries stayed live regardless, because a local deploy does not need a commit
