### stoked ui

- **released:** mit-licensed react components for editing video entirely in the browser. no upload of the raw files before you cut, which keeps it private and fast. early alpha.
- **common:** the shared react utilities and small libraries the other modules lean on.
- **media selector:** a file input that knows about media: thumbnails, metadata extraction, screenshots.
- **file explorer:** built on mui's file explorer with drag and drop, which i had before mui shipped theirs.
- **timeline:** a pro-editor style timeline with play, rewind and fast-forward, and a sequencing engine that tracks media across multiple tracks.
- **editor:** the core component that ties the rest together: a video controller and an interactive screen for editing in real time.
- open for anyone to poke at and contribute: [github.com/stoked-ui/sui](https://github.com/stoked-ui/sui).
