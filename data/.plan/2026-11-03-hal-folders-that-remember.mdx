### rotor

- roster folders remember open and closed across restarts
  - no folder had ever saved its state: the pane, the tree and the products list each held it in plain component state, and the hidden section in a session-only atom
  - saved through the plugin storage the roster already uses for placement, rather than a new store
- an agent's default working directory is now the primary checkout of its repo; 224 tests green on the clean rerun
- pin and unpin built and tested, not integrated: I ran out of turns before the apply step, and the task record was refused, so it sits as a ready patch

### selfactor

- `self session` gained an idle filter and a stop for tracked sessions
  - the tests caught `stop <id> --dry-run` running a real stop, because the flag rule was declared but never enforced; it is enforced in code now
  - 34 unit and 7 subprocess tests, plus the existing session, retire and accounting suites
